# Conversation Agents — source

This folder contains the source code for the conversation agents example. Key components:

- `models/` — Pydantic domain and response models
- `agent/` — Pydantic-AI agent composition and tools
- `api/` — FastAPI routes exposing the agent functionality
- `services/` — ML integration (Hugging Face pipelines)

Use the top-level README for project-level instructions.
